# UI, Mobile & Accessibility Rules

Every UI change or new view MUST satisfy these rules across both light and dark themes:

1. **First-class mobile and desktop layouts:** Both mobile and desktop versions must look intentional and balanced. On mobile, rearrange or stack layouts freely so the screen stays easy to scan, as long as all data and actions remain accessible.
2. **No unexpected horizontal scroll on mobile:** Never let cards, tables, pills, or long strings cause unintended horizontal overflow on mobile viewports (`min-w-0`, `truncate`, `flex-wrap`, or responsive stacking where needed). *(Wide fixed widths guarded by [ui-guards.test.ts](../src/components/ui-guards.test.ts).)*
3. **No visible vertical scrollbars on inner scrollable areas:** For scrollable modals, drawers, and inner panels (such as receipt previews), hide the vertical scrollbar (`[scrollbar-width:none] [&::-webkit-scrollbar]:hidden`) and render subtle top/bottom fade shadows whenever content can scroll up or down. *(Enforced by [ui-guards.test.ts](../src/components/ui-guards.test.ts).)*
4. **WCAG AA contrast in light and dark themes:** All text, icons, badges, inputs, and selected/active states must pass WCAG AA contrast (at least 4.5:1 for normal text and 3:1 for large text and UI components) in both light and dark themes. Avoid hardcoding colors that only work on one theme surface; prefer theme tokens (`--rt-*`) or `text-current` on inverted surfaces. *(Inverted-surface contrast guarded by [ui-guards.test.ts](../src/components/ui-guards.test.ts).)*
5. **Instant feedback on every click and navigation:** Every interactive click (tabs, links, buttons, switches, actions) must respond immediately on press. Never leave the previous view or idle button state frozen while waiting for a lazy JS chunk, route loader, or network request: show an immediate loading state (such as `PageLoading` or an inline spinner/pending label) or an immediate visual transition, and never animate or re-transition the outgoing page while the next route is still loading. *(Router pending config and transition keys guarded by [ui-guards.test.ts](../src/components/ui-guards.test.ts).)*
